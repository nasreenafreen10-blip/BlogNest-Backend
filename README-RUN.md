# BlogNest Backend (sanitized export)

This archive excludes `.env`, API keys, MongoDB credentials, `node_modules`, logs, backups, and uploads.

## Run locally

1. Copy `.env.example` to `.env`.
2. Set `MONGO_URI`, `JWT_SECRET`, and `GEMINI_API_KEY`.
3. Install dependencies:

```powershell
npm install
npm start
```

The API runs at `http://localhost:5000`.
